# Пояснения к коду курсового проекта

> Этот файл не имеет отношения к пояснительной записке. Здесь просто объясняется, что сделано в коде.

## 1. Текущее состояние проекта

На момент первой опроцентовки готова только клиентская часть: приложение для платформы Android на Java (Android Studio). Серверная часть на Spring Boot с базой данных MySQL, REST API, авторизация по JWT-токену и разделение ролей будут разработаны на следующих этапах.

Сейчас клиент работает автономно: данные хранятся на устройстве пользователя во внутренней БД. После появления сервера обращение к данным будет заменено запросами к REST API (планируется Retrofit).

## 2. О стиле кода

Кодовая база не писалась с нуля под этот курсовой проект: раньше это был мой отдельный проект, который я решил развить и взять для курсовой работы. Поэтому стиль кода местами неоднороден: например, названия классов или переменных, разное оформление, комментарии не везде, часть кода ещё не приведена к структуре под клиент-серверную схему. По мере разделения на клиент и сервер я буду приводить код к единому стилю и проводить рефакторинг.

## 3. Что делает приложение

- **Словарь:** добавление, изменение, удаление и поиск слов.
- **Темы:** слова распределяются по темам; темы можно создавать и просматривать.
- **Проверка знаний:** пользователь выбирает темы, приложение выдаёт слова в случайном порядке, пользователь вводит перевод, приложение проверяет ответ.
- **Статистика:** по окончании проверки выводятся количество вопросов, правильных и неправильных ответов и процент правильных.
- **Тексты:** всё то же самое, но для текстов.
